# SENTRY-6G | AIORI-3 Hackathon

**Project:** SENTRY-6G — A Failure-Aware Dialog Continuity and Safe Recovery Framework for Heterogeneous AI-Agent Networks

**Team Name:** Team Sync  
**Team Code:** A3-PS021-TC509  
**Hackathon:** AIORI-3  
**Problem Statement:** PS-021 – Experimental Dialog Correlation and Recovery Across Agent Adapters

## Project Overview

SENTRY-6G is a proposed failure-aware framework designed to maintain dialog continuity and enable safe recovery across heterogeneous AI-agent networks.

The project focuses on reliable interaction tracking, failure detection, and controlled recovery in distributed multi-agent environments, with relevance to emerging 6G and autonomous network systems.
